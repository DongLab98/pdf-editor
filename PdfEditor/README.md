# PDF 편집기 (Windows)

한글 PDF를 위한 편집 프로그램입니다. 글자를 **원래 글꼴 그대로** 고치고, 이미지를 편집하고, 스캔 문서는 **OCR(한국어+영어)** 로 인식해 검색·복사·수정할 수 있습니다.

## 주요 기능 (알PDF 스타일)

화면 위쪽 **리본 메뉴**(홈 · 편집 · 주석 · 페이지 · 변환 · 보안 · 도구 · 보기)에서 기능을 고릅니다. 기능은 이름이 붙은 그룹으로 묶여 있고, 왼쪽 위 **[파일]** 버튼에 열기·저장·인쇄·최근 파일이 있습니다. 여러 문서를 **탭**으로 열고, 페이지를 **이어서 스크롤**하며 봅니다. 아래 상태 표시줄에서 페이지 이동, 확대/축소 슬라이더, OCR 언어를 바꿀 수 있습니다.

| 분류 | 기능 |
|---|---|
| 보기 | 문서 탭, 연속 보기/한 장씩 보기, 폭·쪽 맞춤, 확대/축소, 전체 화면, 페이지 미리보기, 책갈피(목차) 패널, 찾기, 시작 화면과 최근 파일 |
| 텍스트 편집 | **알PDF처럼 페이지 위에서 바로 수정**: 글자를 클릭하면 그 자리에 편집 상자와 서식 도구 모음(글꼴·크기·굵게·기울임·밑줄·색·정렬). 여러 줄 문단은 한 상자로 편집되고 자동 줄바꿈, 상자 이동·폭 조절, 원본 글꼴·크기·색·줄 간격·정렬 유지 |
| 복사·붙여넣기 | Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+A — 글자, 텍스트 상자(같은 서식 그대로), 이미지. 다른 프로그램(워드, 웹, 그림판 등)에서 복사한 글자·그림도 마우스 위치에 붙여넣기 |
| 이미지 편집 | 추가, 이동·크기 조절, 교체, 회전, 반전, 자르기, 밝기·대비, 흑백, 저장, 삭제, 영역 지우기 |
| 주석 | 형광펜, 밑줄, 취소선, 메모(말풍선), 펜, 사각형, 원, 선, 화살표, 링크. 색·불투명도·굵기 변경, 이동, 삭제, 모두 삭제, 주석 병합 |
| 서명·도장 | 전자 서명(직접 그리기/이미지 불러오기, 저장해 두고 재사용), 도장(승인·검토·반려·기밀 등, 날짜 포함) |
| 페이지 | 회전, 빈 페이지·파일 삽입, 삭제, 끌어서 순서 변경, 여러 페이지 선택, 페이지 추출, 분할, 합치기 |
| 꾸미기 | 페이지 번호, 머리글·바닥글({p}, {n}, {date}, {file}), 워터마크(문자/이미지, 각도·진하기·반복) |
| 변환 | PDF → 워드/엑셀/파워포인트/이미지(PNG·JPG)/텍스트, 이미지 → PDF, 문서(워드·엑셀·PPT·한글·텍스트) → PDF |
| 보안 | 암호 설정(AES-256, 인쇄·복사·편집 권한), 암호 해제, 용량 줄이기, 문서 속성 |
| 도구 | 문자인식(OCR, 한국어+영어), 문서 비교(두 PDF의 달라진 글자 표시), 양식(입력란) 채우기, 인쇄 |

### 참고
- **문서 → PDF**는 PC에 설치된 프로그램을 사용합니다. 워드·엑셀·PPT는 Microsoft Office, 한글(HWP)은 한컴오피스 한글, 둘 다 없으면 LibreOffice가 필요합니다. 텍스트(.txt)는 프로그램 없이 변환됩니다.
- **PDF → 워드**는 글꼴, 표, 이미지, 단락을 최대한 살려 편집 가능한 문서로 만듭니다. 스캔 문서는 먼저 OCR을 하세요.
- **PDF → PPT**는 페이지를 보이는 그대로 슬라이드에 넣고, 글자는 슬라이드 노트에 넣습니다.
- PDF → 한글(HWP) 직접 변환과 AI 요약은 지원하지 않습니다. 한글 문서가 필요하면 PDF → 워드로 변환한 뒤 한글에서 여세요.

## 설치 파일 만들기

이 폴더는 소스 코드입니다. 아래 두 방법 중 하나로 Windows 설치 파일(`PdfEditor_Setup_1.0.0.exe`)을 만듭니다.

### 방법 A: Windows PC에서 직접 만들기 (권장)

1. [Python 3.12](https://www.python.org/downloads/)를 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"** 를 꼭 체크하세요.
2. 이 폴더의 **`build_windows.bat`** 를 더블클릭합니다.
   - 필요한 라이브러리 설치 → 실행 파일 생성 → 설치 파일 생성까지 자동으로 진행됩니다. 처음 한 번은 5~10분쯤 걸립니다.
   - 설치 파일을 만드는 도구(Inno Setup)가 없으면 winget으로 자동 설치합니다.
3. 작업이 끝나면 `installer_output` 폴더가 열립니다. **`PdfEditor_Setup_1.0.0.exe`** 를 실행해 설치하세요.

> 설치 파일 없이 바로 쓰려면 `dist\PdfEditor` 폴더를 통째로 복사해 `PdfEditor.exe` 를 실행하면 됩니다(포터블).

### 방법 B: GitHub에서 자동으로 만들기 (PC에 아무것도 설치하지 않음)

1. GitHub에 새 저장소를 만들고 이 폴더 전체를 올립니다(`.github` 폴더 포함).
2. 저장소의 **Actions** 탭에서 "Windows 설치 파일 빌드"가 실행됩니다. 약 10분 걸리며, 빌드 중에 자가 진단(텍스트 편집·글꼴·OCR·저장)도 함께 돌립니다.
3. 완료된 실행을 열고 **Artifacts → PdfEditor-Windows** 를 내려받으면 설치 파일과 포터블 zip이 들어 있습니다.
   - `v1.0.0` 같은 태그를 붙여 올리면 Releases에도 자동으로 첨부됩니다.

## 사용법

- **텍스트 수정**: [텍스트·이미지 편집] 도구에서는 고칠 수 있는 글자에 점선 상자가 표시됩니다. 글자를 클릭하면 그 자리에서 바로 고칠 수 있고, 위에 뜨는 도구 모음으로 글꼴·크기·굵게·기울임·밑줄·색·정렬을 바꿉니다. ✥ 손잡이로 상자를 옮기고, 오른쪽 파란 손잡이로 폭(줄바꿈 너비)을 조절합니다. 상자 밖을 클릭하거나 Ctrl+Enter를 누르면 적용되고, Esc를 누르면 취소됩니다. 도구 모음의 ⋯ 버튼이나 우클릭 → [고급 수정]을 누르면 미리보기가 있는 대화상자가 열립니다.
- **텍스트 상자 이동**: [편집] 도구에서 글자를 누른 채 끌면 같은 글꼴·크기·색 그대로 옮겨집니다(Shift를 누르면 가로·세로로만). 편집 중에는 점선 테두리를 끌어서 옮깁니다.
- **텍스트 추가**: 빈 곳을 더블클릭하거나 [텍스트 추가] 도구로 클릭하세요(폭 자동). 드래그하면 그 폭에서 자동으로 줄이 바뀌는 상자가 만들어집니다. 다 쓰면 [편집] 도구로 자동으로 돌아갑니다.
- **확대/축소**: Ctrl+마우스 휠이나 터치패드 두 손가락 벌리기를 쓰면 마우스가 있는 곳을 기준으로 확대/축소됩니다. Ctrl+0은 실제 크기입니다.
- **복사·붙여넣기**: 글자를 복사하려면 [텍스트 선택] 도구로 드래그한 뒤 Ctrl+C를 누르세요(Ctrl+A는 페이지 전체 선택). 텍스트 상자는 우클릭 → [복사]로 복사하고, Ctrl+V를 누르면 같은 글꼴·크기·색으로 마우스 위치에 붙여넣어집니다. 이미지는 선택한 뒤 Ctrl+C/Ctrl+X를 누르면 됩니다. 다른 프로그램에서 복사한 글자나 그림도 Ctrl+V로 붙여넣을 수 있습니다.
- **주석**: [주석] 탭에서 도구를 고르고 글자를 드래그(형광펜·밑줄·취소선)하거나 그립니다. 만든 주석은 [편집] 도구로 클릭해 선택하고, 우클릭으로 색·불투명도·굵기를 바꿉니다.
- **서명·도장**: [주석] 탭 → [전자 서명]/[도장] → 넣을 위치 클릭. 넣은 뒤 드래그로 옮기고 크기를 바꿀 수 있습니다.
- **텍스트 추가**: [텍스트 추가] 도구로 원하는 위치를 클릭합니다. 가장 가까운 기존 글자의 글꼴과 크기가 기본값으로 잡힙니다.
- **이미지**: 클릭해서 선택한 뒤 드래그로 이동하거나 모서리로 크기를 바꿉니다. 우클릭하면 편집 메뉴가 나오고, Del 키로 삭제합니다.
- **OCR**: 툴바에서 언어(기본 `kor+eng`)를 고르고 [현재 페이지 OCR]을 누릅니다. 전체 페이지는 OCR 메뉴에 있습니다. 인식된 글자는 마우스를 올리면 초록색으로 표시됩니다.
- **줄 전체 선택**([편집] 탭): 꺼져 있으면(기본, 권장) 글꼴·크기·색이 같은 부분만 선택합니다. 켜면 한 줄 전체를 선택합니다.
- 단축키(어느 메뉴 탭에서든 동작): Ctrl+O 열기, Ctrl+S 저장, Ctrl+P 인쇄, Ctrl+W 탭 닫기, Ctrl+Z / Ctrl+Y(Ctrl+Shift+Z) 실행 취소·다시 실행, Ctrl+C/X/V 복사·잘라내기·붙여넣기, Ctrl+A 전체 선택, 방향키로 선택한 그림·주석 미세 이동, Ctrl+F 찾기, Ctrl+B 책갈피, Ctrl+휠 확대·축소, PgUp/PgDn 페이지 이동, F11 전체 화면, Esc 선택 해제

## "원본 글꼴 그대로"의 동작 방식

PDF에는 보통 문서에 **쓰인 글자만** 들어 있는 글꼴(서브셋)이 내장되어 있습니다. 그래서 프로그램은 글자 하나하나에 대해 아래 순서로 글꼴을 고릅니다.

1. **PC에 같은 이름의 글꼴이 설치되어 있으면** 그 글꼴을 씁니다. 원본과 100% 같은 글꼴이고, 어떤 글자든 쓸 수 있습니다.
2. **PDF에 내장된 원본 글꼴**을 재사용합니다. 문서 어딘가에 이미 쓰인 글자는 원본 모양 그대로 나옵니다.
3. 원본에 없는 글자만 **비슷한 스타일의 대체 글꼴**로 씁니다(고딕 → 맑은 고딕, 명조 → 바탕, 굵게 → 굵게).

수정 대화상자에 실제로 쓰일 글꼴이 표시되고, 대체 글꼴이 섞이면 경고가 나옵니다. 문서에 쓰인 글꼴(예: 나눔고딕, 함초롬바탕, KoPub 등)을 PC에 설치하면 어떤 글자든 원본과 똑같이 고쳐집니다. 글꼴 목록에서 다른 글꼴을 직접 고를 수도 있습니다.

저장할 때는 실제로 쓴 글자만 글꼴에 포함하므로 파일 크기가 거의 늘지 않습니다.

## OCR 언어 추가

`tessdata` 폴더(설치 후에는 `C:\Program Files\PdfEditorKR\_internal\tessdata`)에
[tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)의 `*.traineddata` 파일(예: `jpn`, `chi_sim`)을 넣고 프로그램을 다시 시작하면 언어 목록에 나타납니다.

## 알아둘 점

- 새 글자가 원래보다 길면 옆 내용과 겹칠 수 있습니다. 글자 크기를 줄이거나 문장을 나눠 주세요.
- 글자를 윤곽선(도형)으로 바꿔 저장한 PDF는 텍스트가 없으니, OCR을 먼저 하거나 영역 지우기와 텍스트 추가를 함께 쓰세요.
- 이동하거나 회전한 이미지는 원래 기울기(회전 변환)가 초기화됩니다.
- 암호를 풀어 연 PDF는 암호 없이 저장됩니다.

## 소스에서 바로 실행 (개발용)

```bat
py -3 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

설치나 빌드를 확인하려면 `PdfEditor.exe --selftest` 를 실행하세요. 결과는 `%TEMP%\pdfeditor_selftest.txt` 에 저장됩니다.

## 구성

```
main.py                 실행 진입점
pdfeditor/engine.py     PDF 편집 엔진(텍스트/이미지/OCR/페이지/실행 취소)
pdfeditor/fontmgr.py    원본 글꼴 유지 로직(시스템 글꼴 색인, 내장 글꼴 복원, 글자별 대체)
pdfeditor/annots.py     주석·텍스트 선택·양식
pdfeditor/tools.py      합치기·분할·페이지 번호·워터마크·비교·도장 등 문서 도구
pdfeditor/convert.py    PDF ↔ 워드/엑셀/PPT/이미지/텍스트, Office·한글 → PDF
pdfeditor/canvas.py     페이지 화면과 마우스 조작
pdfeditor/dialogs.py    텍스트·이미지 대화상자
pdfeditor/tool_dialogs.py 문서 도구 대화상자
pdfeditor/mainwindow.py 메인 창(리본, 탭, 연속 보기, 패널)
pdfeditor/theme.py      화면 테마(색, 아이콘, 스타일시트)
pdfeditor/ribbon.py     리본 메뉴
pdfeditor/inline_editor.py 페이지 위 직접 텍스트 편집
tessdata/               OCR 언어 데이터(한국어, 영어)
build_windows.bat       Windows 설치 파일 자동 생성
installer.iss           Inno Setup 설치 스크립트
PdfEditor.spec          PyInstaller 설정
```

아이콘: Lucide(ISC). 사용 라이브러리: PyMuPDF(AGPL-3.0), PySide6(LGPL-3.0), pdf2docx(현재 MIT로 재라이선스됨), python-docx·python-pptx·openpyxl(MIT), OpenCV(Apache-2.0), numpy(BSD), fontTools(MIT), Pillow(MIT-CMU), Tesseract 언어 데이터(Apache-2.0).
PyMuPDF가 AGPL이므로 이 프로그램을 외부에 배포할 때는 소스를 함께 공개해야 합니다(개인·사내 사용은 문제없음).

## 광고와 개인정보
- 이 프로그램은 무료이며, 시작 화면과 문서 아래에 배너 광고가 표시됩니다. 문서 아래 광고는 ✕를 눌러 그 실행 동안 숨길 수 있습니다.
- 프로그램은 광고 목록(ads.json)과 배너 그림만 인터넷에서 내려받습니다. 문서 내용이나 개인 정보는 어디에도 보내지 않습니다.
- 광고 운영 방법은 `ads_server/광고_설정_방법.md`를 참고하세요.
