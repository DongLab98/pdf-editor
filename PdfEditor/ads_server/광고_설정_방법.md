# PDF 편집기 광고 설정 방법

프로그램은 실행될 때 인터넷에 올려 둔 **ads.json** 파일을 읽어서 광고를 보여 줍니다.
그래서 광고를 바꾸고 싶으면 **이 폴더의 파일만 고쳐서 다시 올리면 됩니다.** 프로그램을 업데이트할 필요가 없습니다.
(사용자 PC는 3시간마다 새 광고를 확인하고, 인터넷이 안 되면 마지막으로 받은 광고를 보여 줍니다.)

광고가 나오는 곳은 두 군데입니다.

| 자리 | 크기(권장 그림) | 언제 보이나 |
|---|---|---|
| 시작 화면 (`home`) | 728×90 (두 배 크기 1456×180이면 더 선명) | 프로그램을 켜면, 문서를 모두 닫았을 때 |
| 문서 아래 띠 (`bar`) | 468×60 (두 배 크기 936×120) | 문서를 열어 둔 동안. 사용자가 ✕를 누르면 그 실행 동안 숨김 |

광고 여러 개를 넣으면 40초마다 번갈아 나옵니다. 모든 배너에는 법에 따라 "광고" 표시가 자동으로 붙습니다.

---

## 1. 처음 한 번만: GitHub Pages에 올리기 (무료)

1. https://github.com 에 가입합니다.
2. 오른쪽 위 **+ → New repository** → 이름은 `pdfeditor-ads` → **Public** → Create.
3. **Add file → Upload files**로 이 폴더의 파일을 모두 올립니다.
   (`ads.json`, `*.png`. 이 안내 파일은 올리지 않아도 됩니다)
4. 저장소의 **Settings → Pages** → Branch를 `main`으로 → Save.
5. 1~2분 뒤 아래 주소가 브라우저에서 열리면 성공입니다.
   **https://donglab98.github.io/pdfeditor-ads/ads.json**
   (프로그램에는 이 주소가 이미 들어 있습니다. 저장소 이름을 꼭 `pdfeditor-ads`로 만드세요.)

## 1-1. 프로그램 링크 (블로그·다운로드·문의)

`ads.json` 맨 위 `links` 칸의 주소가 프로그램의 [사용법 블로그] 버튼, 시작 화면 링크, [정보] 창에 쓰입니다.
빈칸(`""`)이면 그 버튼은 숨겨집니다.

```json
"links": {
  "blog": "https://donglab.tistory.com",
  "download": "https://github.com/donglab98/pdf-editor/releases",
  "source": "https://github.com/donglab98/pdf-editor",
  "contact": "mailto:내이메일@gmail.com"
}
```

## 2. 광고 바꾸기

GitHub 저장소에서 `ads.json`을 열고 연필 아이콘(Edit)을 눌러 고친 뒤 **Commit changes**를 누르면 끝입니다.
새 그림은 **Add file → Upload files**로 올립니다.

```json
{
  "rotate_sec": 40,
  "ads": [
    {
      "id": "광고마다-다른-이름",
      "slots": ["home", "bar"],
      "image": "시작화면용_728x90.png",
      "image_bar": "아래띠용_468x60.png",
      "text": "그림을 못 받았을 때 대신 보일 글",
      "url": "https://클릭하면-열릴-주소",
      "note": "마우스를 올리면 보일 설명 (제휴 광고 고지문 등)",
      "weight": 1,
      "start": "2026-12-01",
      "end": "2026-12-31"
    }
  ]
}
```

| 항목 | 설명 |
|---|---|
| `slots` | 어디에 보일지. `["home"]` 시작 화면만, `["bar"]` 아래 띠만 |
| `image` / `image_bar` | 그림 파일 이름(같은 폴더) 또는 https 주소. `image_bar`가 없으면 `image`를 줄여서 씀 |
| `url` | 클릭하면 열릴 주소. `https://…` 또는 `mailto:메일주소` (보안상 `http://`는 무시됨) |
| `weight` | 노출 비중. 2로 두면 1인 광고보다 두 배 자주 나옴 (광고비를 더 낸 곳에 사용) |
| `start` / `end` | 광고 기간. 기간이 지나면 자동으로 사라짐 (계약 기간 관리에 편리) |
| `note` | 제휴·협찬 고지문 |

⚠️ JSON은 쉼표 하나만 틀려도 읽히지 않습니다(그러면 프로그램은 예전 광고를 계속 보여 줍니다).
고친 뒤 https://jsonlint.com 에 붙여 넣어 확인하면 안전합니다.

## 3. 돈이 되는 광고 넣는 법

1. **블로그 홍보 배너 (이미 들어 있음)**
   예시 `blog` 광고는 프로그램 사용자를 동랩 블로그로 보냅니다. 블로그에 붙인 구글 애드센스 수익으로 이어집니다.
2. **광고 자리 직접 판매 (수익이 가장 큼)**
   예시 `inquiry` 광고("이 자리에 광고하세요")의 `mailto:` 뒤에 내 이메일을 넣어 두세요.
   - 사용자가 늘면 PDF·문서·사무용품·스캐너·전자계약 업체 등에 "월 ○○만 원, 기간 ○일"로 팝니다.
   - 계약하면 업체가 보내 준 배너 그림을 올리고, `start`/`end`에 계약 기간을 적으면 됩니다.
   - 노출 수를 알려 주려면 클릭 주소를 bit.ly 같은 단축 주소로 만들어 클릭 수를 보여 주면 됩니다.
3. **제휴 마케팅 (쿠팡 파트너스 등)**
   상품 링크를 `url`에 넣고, 사용자가 그 링크로 구매하면 수수료를 받습니다.
   - `note`에 **"쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."** 같은 고지문을 꼭 넣으세요(공정위 추천·보증 심사지침).
   - 프로그램 안에 링크를 넣어도 되는지는 해당 제휴 프로그램의 약관을 먼저 확인하세요.

## 4. 광고를 모두 끄려면

`ads.json`의 `"ads": [ ... ]` 안을 비워서 `"ads": []`로 올리면, 다음 확인 때부터 모든 사용자에게 광고가 사라집니다.
